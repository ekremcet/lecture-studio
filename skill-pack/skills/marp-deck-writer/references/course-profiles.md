# Course profiles (template)

Facts for title slides, closing slides, and tone. Use this file only when the open course has no `studio.json`,
`AGENTS.md` (or an older `CLAUDE.md`), or syllabus of its own; for any real presenter the facts live in
`studio.json` at the repo root and in the course folder. "unknown" means the repo does not say: ask rather
than invent, and never copy the placeholder names, emails, or links below into a deck.

## CS221 - Principles of Software Engineering (example)

- Language: English. Semester: Fall. Credits: 3 local / 6 ECTS. Prerequisite: none.
- Textbook: Ian Sommerville, Software Engineering, 10th edition. Weekly readings per syllabus.
- Project: team project (2-4 people), five deliverables D1 (project plan), D2 (requirements), D3 (design),
  D4 (test plan and implementation), D5 (final delivery and presentation). Running example in slides: CampusPal.
- Grading: Project package D1-D5 incl. presentation 40%, Midterm 25%, Final 35%.
- Weekly pairing: each `weekN/` also has `weekN-instructor-guide.md`.
- Office hours: unknown. Course repo: unknown. Email: from `studio.json`.

## CS231 - Data Structures and Algorithms (example)

- Language: English. Semester: Fall. Prerequisite: none.
- Textbook: Mark Allen Weiss, Data Structures and Algorithm Analysis in C++, 4th edition.
- Programming language: C++. Labs: 30% of the grade. Midterm 30%, Final 40%.
- Practice resources named in decks: https://visualgo.net, https://www.bigocheatsheet.com
- Office hours: unknown. Course repo: unknown. Email: from `studio.json`.
