# Block types and their internal timing

Standard three-hour rhythm: block, 5-minute break, block, 15-minute break, repeated three times; the last 15 minutes are questions, project clinic, exit ticket, or a final long break.

| Time | Activity |
|---|---|
| 00:00–00:20 | Block 1 |
| 00:20–00:25 | Short break |
| 00:25–00:45 | Block 2 |
| 00:45–01:00 | Long break |
| 01:00–01:20 | Block 3 |
| 01:20–01:25 | Short break |
| 01:25–01:45 | Block 4 |
| 01:45–02:00 | Long break |
| 02:00–02:20 | Block 5 |
| 02:20–02:25 | Short break |
| 02:25–02:45 | Block 6 |
| 02:45–03:00 | Questions, project clinic, exit ticket |

## Concept block

12-14 minutes explanation, 4-5 minutes worked example, 2-3 minutes retrieval check (a Question slide answered by show of hands or one-line writing).

## Practice block

4-5 minutes setup (state the timebox and the required output), 8-10 minutes student work while you visit groups, 5-7 minutes debrief. Reveal the sample answer only during the debrief.

## Studio block

Students apply the week's ideas to their own project or lab and leave with a small, reviewable artifact: a process map, a requirement set, a test strategy, a diagram, a design decision record. Name the deliverable it feeds.

## Late class

Use the minimum viable path. Move worked examples and secondary catalogues to self-study. Keep the practice and its debrief.

## Early class

Use the extension. Do not introduce a new theory topic that will not be assessed.
